Embedding Your Trading Dashboard in Notion

A complete step-by-step guide — from file to fully embedded live dashboard

What you have: A self-contained HTML dashboard file (trading_dashboard.html) that tracks your trades, calculates stats, and renders live charts. To embed it in Notion, you need to host it online first — this guide covers exactly how to do that for free.

STEP 1 — Choose a Hosting Method

Notion can only embed things with a public URL. Pick one of these free options:

Easiest
Netlify Drop
Drag and drop your HTML file onto a webpage. Get a live URL in under 60 seconds. No account required to start. Free forever.
Free
GitHub Pages
Upload to a GitHub repo, enable Pages, get a permanent URL. Takes 5 minutes. Free forever. Best if you want version history.

Recommendation: Use Netlify Drop for the fastest setup. Use GitHub Pages if you want a permanent URL that survives forever even if Netlify changes their free plan.

OPTION A — Netlify Drop (Fastest — 60 seconds)

1
Open Netlify Drop
Go to drop.netlify.com in your browser. You will see a large drag-and-drop zone. No account needed for the first deploy.
2
Drag your HTML file onto the page
Find your trading_dashboard.html file (it was downloaded from this conversation). Drag it directly onto the Netlify Drop zone. Wait about 10 seconds.
3
Copy your live URL
Netlify will give you a URL that looks like this:
https://luminous-tartufo-abc123.netlify.app
Copy this URL — you'll paste it into Notion in the next section. Test it first by opening it in a new browser tab and confirming your dashboard loads.

OPTION B — GitHub Pages (Permanent URL)

1
Create a free GitHub account
Go to github.com and sign up (free). Skip this if you already have an account.
2
Create a new repository
Click the green New button. Name the repo trading-dashboard. Set it to Public. Check "Add a README file". Click Create repository.
3
Upload your HTML file
Inside the repo, click Add file → Upload files. Drag your trading_dashboard.html file into the upload zone. Rename it to index.html before uploading (this is important). Click Commit changes.
4
Enable GitHub Pages
Go to your repo → Settings → scroll down to Pages. Under "Branch", select main and click Save. Wait 1–2 minutes, then your URL will appear:
https://yourusername.github.io/trading-dashboard/

STEP 2 — Embed the Dashboard in Notion

Once you have your live URL, embedding in Notion takes under 30 seconds.

1
Open your Dashboard page in Notion
Navigate to your 🏠 Dashboard page (the one you created in Module 3 of the build guide). Position your cursor where you want the dashboard to appear — typically below any existing text blocks.
2
Type /embed and press Enter
Notion will show a text input. Paste your live URL from Step 1 into the box and press Enter or click Embed link. Notion will load a preview of your dashboard.
3
Resize the embed block
Hover over the embed block and drag the bottom edge downward to make it taller. For the full dashboard experience, drag it to at least 700–900px tall. You can also drag the sides to control width.
4
Set Notion to Full Width (important)
Click the ... menu at the top right of the Notion page → click Full width to toggle it ON. This gives your embed the maximum space and makes charts much more readable.
Your dashboard is now live inside Notion. Every time you open that page, the embed loads your dashboard. Any trades you add through the dashboard's "+ Add Trade" button are saved to your browser's local storage and persist between sessions.

STEP 3 — Add Trades to Your Dashboard

1
Click "+ Add Trade" inside the embed
The button is in the Trade Log section at the bottom of your dashboard. A form will appear where you fill in the trade details.
2
Fill in the fields and click Save
Enter the date, symbol, account name, setup name, direction, emotion, P&L amount, and your risk amount. Click Save Trade. All charts and stats update instantly.
3
Remove the sample data
The dashboard loads with sample trades pre-filled so it doesn't look empty on first load. Delete these by clicking the × button on each row in the Trade Log table.

Frequently Asked Questions

Will my trade data be lost if I close the browser?
No. Trades are saved to your browser's local storage automatically. They persist across sessions on the same device and browser. However, if you use a different device or clear your browser data, the trades won't carry over. For cross-device sync, the best approach is to use the Notion Trades database (from the build guide) as your source of truth and use this dashboard as a visual layer.
What if the embed shows a "Can't embed this URL" error in Notion?
Some domains aren't embeddable due to their security headers. Netlify Drop and GitHub Pages both work reliably with Notion embeds. If you get an error, try a different hosting option. Also confirm your URL starts with https:// (not http).
The embed shows but the charts don't load. What do I do?
This usually means Chart.js didn't load from its CDN. Check that you have an internet connection. If you're on a corporate network, Chart.js's CDN might be blocked. In that case, you can download Chart.js separately and host it alongside the HTML file — reach out for help with this.
Can I update the HTML file later and keep my data?
Yes. Your trade data is stored in your browser's local storage, not in the HTML file itself. You can update the file, re-upload to Netlify or GitHub, and your data stays intact as long as you're on the same device and browser.
Can multiple people use the same dashboard?
Each person's data is stored locally in their own browser, so yes — you can share the URL and each person sees their own trades. Data does not sync across users.
How do I update the file on Netlify after making changes?
Go back to drop.netlify.com, sign into your Netlify account, find your site, and drag the updated file onto it again. Your URL stays the same. For GitHub Pages, simply upload the new file to the same repo and it auto-deploys.
